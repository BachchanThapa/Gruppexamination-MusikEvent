## 1. Vad innebär semantisk HTML och varför har ni använt det på er eventsida?

### Semantisk HTML betyder att vi använder HTML-taggar som beskriver innehållet, till exempel header, nav, main, section, article och footer. Vi har använt det för att göra sidan tydligare och lättare att förstå. 
### Semantisk kod gör det även lättare för skärmläsare och andra hjälpmedel att förstå strukturen bättre och detta kan då guida tex synskadade rätt på hemsidan.

## 2. Hur fungerar arv i CSS? Ge ett exempel från er egen kod.

### Arv betyder att vissa CSS-egenskaper förs vidare från ett föräldraelement till dess barn. Till exempel om vi sätter color på body, kan texten i elementen under ärva samma färg.

## 3. Vad är den största skillnaden mellan Flexbox och CSS Grid, och när ska man använda vilket verktyg?

### Flexbox passar bäst för en riktning, alltså rad eller kolumn. Grid passar för två riktningar, alltså rader och kolumner. På vår sida använder vi Grid för schemat eftersom vi har tider och scener i rader och kolumner. Vi använder Flexbox för highlightskorten eftersom korten ska ligga bredvid varandra och anpassa sig efter utrymmet.
